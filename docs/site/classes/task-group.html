TaskGroup

Collects tasks for coordinated scheduling, cancellation, and result handling. Tasks retain their insertion order in the group.

Source: fr_async/classes.py:261

Constructor

TaskGroup() -> None

Creates an empty group with started = False and an empty tasks list.

Public state

  • tasks is the list of tasks in insertion order.
  • started records whether run() has been called.

Public methods

add

def add(self, task: Task, autorun: bool = True) -> Task: ...

Adds a task unless it is already in the group. If the group has started, autorun is true, and the task is unfinished, it is scheduled immediately. Returns the supplied task.

collect

def collect(self, *, background: bool = False) -> TaskGroupCollect[Any]: ...

Creates a TaskGroupCollect message. Its result list uses the group's task order.

as_completed

def as_completed(
    self, *, background: bool = False
) -> TaskGroupAsCompleted[Any]: ...

Creates a TaskGroupAsCompleted message. Its iterator yields results in completion order.

cancel

def cancel(self): ...

Calls stop() on every task. Stopping is cooperative: each task stops when it next runs.

run

def run(self, background: bool = False) -> TaskGroupCollect[Any] | None: ...

Marks the group as started and schedules every unfinished task. Returns None when background=True; otherwise returns a collection message that can be yielded by the current task.

join

def join(self, *, background: bool = False) -> TaskGroupCollect[Any]: ...

Creates a collection message for waiting on every task. It does not schedule the tasks; call run() or schedule them separately.

Container methods

  • iter() iterates over tasks in insertion order.
  • len() returns the number of tasks.
  • contains(task) tests membership.

Example

from fr_async import Task, TaskGroup

def worker(value: int) -> int:
    return value * 2

def main():
    group = TaskGroup()
    group.add(Task(worker, 2))
    group.add(Task(worker, 3))
    results = yield group.run()
    return results
