fr_async

The package root re-exports the main runtime entry points and the fr_async.messages module.

Source: fr_async/<strong>init</strong>.py:1

Explicit package exports

The package's all contains:

  • EEVDFScheduler — scheduler class.
  • ExecutionLoop — event loop.
  • File — file wrapper.
  • Task — task object.
  • TaskGroup — task collection.
  • Yieldable — callable wrapper.
  • getEventLoop — current loop accessor.
  • messages — the fr_async.messages module.

These are the names included by from fr_async import *.

Message classes at the package root

fr_async.init also performs from .messages import *, so names in fr_async.messages.all are available for explicit imports from the package root, for example from fr_async import Sleep. However, those names are not included in the package's own all; they are therefore omitted by from fr_async import *. Importing message classes from fr_async.messages makes the intended module boundary explicit.
