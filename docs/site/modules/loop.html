fr_async.loop

Contains the event-loop implementation and the accessor for the most recently created loop.

Public classes

  • ExecutionLoop — runs tasks, handles yielded messages, and coordinates timers, sockets, and thread-pool completions. Source

Public functions

getEventLoop

def getEventLoop(): ...

Returns the module-level loop instance. Raises NoEventLoopException when no ExecutionLoop has been constructed.

Source

Notes

Constructing an ExecutionLoop replaces the module-level loop reference used by messages. The implementation is designed around that shared reference, not independent concurrently active loops.
