fr_async.http_bench

A standalone HTTP/1.1 GET benchmark client. It is separate from the cooperative runtime API and uses Linux select.epoll directly.

Run it as a module:

python -m fr_async.http_bench \
  --host 127.0.0.1 \
  --port 5000 \
  --path / \
  --concurrency 64 \
  --duration 30 \
  --timeout 1

The defaults are host 127.0.0.1, port 5000, path /, concurrency 20, duration 10 seconds, and timeout 5 seconds. The benchmark prints request throughput, errors, latency percentiles, a one-percent-low rate, and HTTP status counts.

Scope and limitations

The tool creates a fresh connection for each request and sends a single GET request with Connection: close. Its response reader uses Content-Length when present and otherwise waits for connection close; it does not implement HTTP chunked-transfer decoding. It requires Linux because it uses select.epoll.
